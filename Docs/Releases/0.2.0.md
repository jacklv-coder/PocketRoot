# PocketRoot 0.2.0

[简体中文](0.2.0.md) | [English](../en/Releases/0.2.0.md) | [文档中心](../README.md)

发布日期：2026-08-04

`v0.2.0` 是 PocketRoot 的第二个公开源码与 Swift Package 版本。

**Embed a local Linux Terminal and Files workspace in any iOS app.**

## 主要能力

- 宿主可直接打开 UIKit / SwiftUI Terminal、Files 或共享会话的 Workspace 页面；
- `PocketRootIshWorkspaceHost` 自动完成调用方 RootFS 的 prepare、boot 与页面接入；
- SwiftTerm 持久 PTY 支持输入、resize、signal、EOF、有序关闭，以及 iPhone 软键盘
  Esc、Tab、Ctrl-C、Ctrl-D、历史键和收起键盘工具栏；
- Files 支持按需树形展开、目录导航、有界预览、创建、原子无覆盖重命名、确认删除，
  以及系统文件导入和分享导出；
- RootFS 安装器提供固定清单校验、snapshot、安全解包、容量预检、事务 promotion、
  复用、回滚和异常恢复；
- 外部消费者 App 按公开 Git SHA 验证冷启动 Terminal/Files、前后台恢复和 shutdown；
- Xcode 16 / iOS 18 CI 持续覆盖 RootFS、原生 runtime、iPhone UI 和公开接入路径；
  iPad Simulator 在里程碑与发布候选时集中验证。

## 真机证据

Jack iPhone（iPhone 14 Pro / iOS 26.6）使用 Xcode 26.6 完成默认 90×2 秒
真机稳定性门禁。20 项检查全部通过：一个 PTY 保持 90 轮，逐字节验证 576 KiB
带唯一边界的零字节流，并交叉执行一次性命令、Files 预览和 stdout 上限故障恢复。
热身后 `phys_footprint` 增长 0.0 MiB，生命周期峰值 83.2 MiB，低于 256 MiB 门禁。

## Swift Package 接入

公共 API 仍为 Experimental，建议固定精确版本：

```swift
dependencies: [
    .package(
        url: "https://github.com/jacklv-coder/PocketRoot.git",
        exact: "0.2.0"
    )
]
```

默认 `PocketRoot` 产品提供 Core、Resources、Terminal 和现成 UI；需要真实 iSH
runtime 时，额外显式选择 `PocketRootIshRuntimeIntegration`。

## 发布边界

本版本只发布 Git tag 对应的 PocketRoot 源码与 Swift Package 元数据。它不授权或
附加 RootFS、App、archive、IPA、XCFramework 镜像或二进制 SDK；GitHub Release
不附加这些制品。
RootFS 继续由调用方合法取得、审核并作为本地输入提供；Runtime/App/二进制分发和
RootFS 再分发保持 fail-closed。

源码发布审计要求全部源码门禁 Ready，并生成带 commit、archive SHA-256、文件统计和
精确授权状态的 JSON 报告，但不保留或上传源码 tar。

## 已知限制

- 原生 Agent UI、streaming 与会话持久化（按产品决定暂停）。
