# PocketRoot 0.1.0

[简体中文](0.1.0.md) | [English](../en/Releases/0.1.0.md) | [文档中心](../README.md)

发布日期：2026-07-31

`v0.1.0` 是 PocketRoot 的首个公开源码与 Swift Package 版本。

**Embed a local Linux Terminal and Files workspace in any iOS app.**

## 主要能力

- 可直接展示的 UIKit / SwiftUI Terminal、Files 与 Workspace 页面；
- 基于 SwiftTerm 的持续交互 PTY，会话支持输入、resize、signal、EOF 与有序关闭；
- guest 文件树按需原地展开、目录导航、有界预览和安全增删改；
- 系统文件选择器导入与分享面板导出；
- RootFS 的校验、安全安装、复用和异常恢复；
- 显式 opt-in 的 iSH runtime 组合入口，以及有界命令和生命周期 Swift API；
- iPhone/iPad Simulator、外部消费者 App、Xcode 16 与签名 iPhone 的工程验证。

## Swift Package 接入

公共 API 仍为 Experimental。建议固定精确版本：

```swift
dependencies: [
    .package(
        url: "https://github.com/jacklv-coder/PocketRoot.git",
        exact: "0.1.0"
    )
]
```

默认产品 `PocketRoot` 提供 Core、Resources、Terminal 和现成 UI。需要真实 iSH
runtime 时，额外显式选择 `PocketRootIshRuntimeIntegration`。

## 发布边界

本版本只发布 Git tag 对应的 PocketRoot 源码与 Swift Package 元数据。GitHub Release
不附加 RootFS、App、archive、IPA、XCFramework 镜像或二进制 SDK。

RootFS 仍由调用方自行合法取得、审查并作为本地输入提供。Runtime、App、TestFlight、
App Store 和二进制 SDK 分发继续受独立的 fail-closed 门禁约束；MIT License 不会
重新许可第三方组件、预编译制品或 RootFS 内容。

## 已知限制

- 公共 API 与原生 runtime 仍为 Experimental；
- 每个宿主进程只支持一次有效 iSH boot/shutdown 生命周期；
- 原生 runtime 只支持 iOS 18+ 的 arm64 真机与 arm64 Simulator；
- iPad 真机、真实 storage pressure、jetsam、强制断电和最终发行制品合规尚未闭环；
- 原生 Agent UI、streaming 与会话持久化不属于本版本默认闭环。
