# PocketRoot 0.1.0

[简体中文](../../../Docs/Releases/0.1.0.md) | [English](0.1.0.md) | [Documentation](../README.md)

Release date: 2026-07-31

`v0.1.0` is the first public PocketRoot source and Swift Package release.

**Embed a local Linux Terminal and Files workspace in any iOS app.**

## Highlights

- Ready-made UIKit and SwiftUI Terminal, Files, and Workspace screens.
- Persistent interactive PTY sessions powered by SwiftTerm, including input,
  resize, signals, EOF, and ordered shutdown.
- Lazy inline guest file trees, directory navigation, bounded previews, and
  safe create, rename, and delete operations.
- Import through the system document picker and export through the share sheet.
- RootFS verification, safe installation, reuse, and interrupted recovery.
- Explicit opt-in iSH runtime composition plus bounded command and lifecycle
  Swift APIs.
- Engineering validation on iPhone/iPad Simulators, an external consumer App,
  Xcode 16, and a development-signed iPhone.

## Swift Package integration

The public API remains Experimental. Pin the exact release:

```swift
dependencies: [
    .package(
        url: "https://github.com/jacklv-coder/PocketRoot.git",
        exact: "0.1.0"
    )
]
```

The default `PocketRoot` product provides Core, Resources, Terminal, and
ready-made UI. Select `PocketRootIshRuntimeIntegration` explicitly when the App
needs the native iSH runtime.

## Release boundary

This release publishes only the PocketRoot source and Swift Package metadata at
the Git tag. The GitHub Release attaches no RootFS, App, archive, IPA,
XCFramework mirror, or binary SDK.

The caller must lawfully obtain and review its own local RootFS input. Runtime,
App, TestFlight, App Store, and binary SDK distribution remain behind separate
fail-closed gates. The MIT License does not relicense third-party components,
prebuilt artifacts, or RootFS contents.

## Known limitations

- The public API and native runtime remain Experimental.
- Each host process supports only one valid iSH boot/shutdown lifecycle.
- The native runtime supports iOS 18+ arm64 devices and arm64 Simulators only.
- Physical iPad, real storage pressure, jetsam, forced power loss, and final
  distribution-artifact compliance remain open.
- Native Agent UI, streaming, and session persistence are outside this default
  release closure.
